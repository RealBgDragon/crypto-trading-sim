# crypto-trading-sim
Requirements
JDK 17+
Node.js 18+ and npm
MySQL Server (local or remote)

📂 Project Structure

/backend (Java Spring Boot)
/frontend (React)

🚀 Backend (Java Spring Boot)
Install JDK and set JAVA_HOME if not already set.
Import the project as a Maven Project.
Configure application.properties (or application.yml) with database credentials and connection settings.
Ensure required dependencies are in pom.xml (Spring Web, Spring Data JPA, MySQL Driver, etc.)

Run the application:
./mvnw spring-boot:run
or from an IDE.

🎨 Frontend (React)
Install Node.js and npm.
Navigate to the frontend directory:
cd frontend

Install dependencies:
npm install

Start the development server:
npm run dev

The files for the db are also included in the project folder
